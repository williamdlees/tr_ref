
10x sequences from the following projects were downloaded from SRA and extracted to Cellranger.
See example files download_sras and process*.slurm in this directory
PRJNA747292
PRJNA603748
PRJNA1083421




Contigs were annotated with the reference set in ../ricotta_june_2 using the commands below.
consolidated contigs from all samples:  http://vdjbase-distribution.s3-website-us-east-1.amazonaws.com/tcr_set/aug_28/all_10x_projects_all_contigs.fasta.gz
annotation file:  http://vdjbase-distribution.s3-website-us-east-1.amazonaws.com/tcr_set/sep_25/all_10x_projects_all_contigs.tsv.gz
reference set:    http://vdjbase-distribution.s3-website-us-east-1.amazonaws.com/tcr_set/sep_25/tr_ref_aug_28_updated_filters_sep_25.zip

docker run -it -v "%cd%":/data:z immcantation/suite:4.6.0 bash

export IGDATA=/usr/local/share/igblast

pushd ../ricotta_aug_28/db
makeblastdb -parse_seqids -dbtype nucl -in ricotta_TRV.fasta
makeblastdb -parse_seqids -dbtype nucl -in ricotta_TRJ.fasta
makeblastdb -parse_seqids -dbtype nucl -in ricotta_TRD.fasta
popd

time igblastn \
   -germline_db_V ../ricotta_aug_28/db/ricotta_TRV.fasta \
   -germline_db_J ../ricotta_aug_28/db/ricotta_TRJ.fasta \
   -germline_db_D ../ricotta_aug_28/db/ricotta_TRD.fasta \
   -query all_10x_projects_all_contigs.fasta \
   -auxiliary_data ../ricotta_aug_28/ricotta_TR.aux \
   -custom_internal_data ../ricotta_aug_28/ricotta_TR.ndm \
   -show_translation -outfmt 19 >all_10x_projects_all_contigs.tsv
